## 2주 제작을 시작하는 조건

W8까지 API계약, 실제검색, 영속DB, 권한/검토, 재현기동, dev20/동결holdout30이 준비되어야 한다. 현재 저장소는 API접수/인메모리조회 뼈대다. 제공한8개CPU실습을 통과했다고 이 준비조건이 충족되는 것은 아니다. 실제 모델 접근/예산이 없으면 fixture프로토타입 상태를 표시하고 실제 평가 gate는 남겨 둔다.
